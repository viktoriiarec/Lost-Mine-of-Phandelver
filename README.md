# Lost Mine of Phandelver — Unity Prototype

Неофициальный учебный прототип приключенческой RPG на Unity, основанный на концепте **Lost Mine of Phandelver**: герои сопровождают груз к Фандалину, сталкиваются с гоблинской засадой и постепенно выходят на след затерянной шахты.

## Вертикальный срез

Первая версия охватывает небольшой игровой эпизод:

1. знакомство с героями и заданием;
2. путь к Фандалину;
3. обнаружение гоблинской засады;
4. проверка Восприятия по правилам `d20 + модификатор + бонус мастерства`;
5. выбор: исследовать следы, поговорить с пленником или вступить в бой;
6. переход к следующей сцене в зависимости от результата.

Подробности: [docs/VERTICAL_SLICE.md](docs/VERTICAL_SLICE.md).

## Быстрый запуск

1. Установить Unity 6 LTS.
2. Клонировать репозиторий и добавить его корневую папку в Unity Hub.
3. Дождаться импорта без красных ошибок.
4. Выбрать **Tools → Lost Mine of Phandelver → Create Demo Scene**.
5. Нажать **Play**.
6. Для тестов открыть **Window → General → Test Runner → EditMode → Run All**.

Подробная инструкция: [docs/UNITY_SETUP_RU.md](docs/UNITY_SETUP_RU.md).

## Технологии и архитектура

- Unity 6 LTS и C#;
- шесть характеристик: Сила, Ловкость, Телосложение, Интеллект, Мудрость, Харизма;
- проверки `d20` против класса сложности;
- ScriptableObject для будущих персонажей, предметов и встреч;
- обычные C#-классы для правил;
- MonoBehaviour только для Unity-жизненного цикла и отображения.

## Правила разработки

- `main` должна содержать запускаемое состояние проекта.
- Одна задача — одна ветка и один pull request.
- UI не рассчитывает правила игры.
- Новая механика сопровождается тестом.
- Сторонние материалы добавляются только с понятной лицензией.
- Тексты и иллюстрации опубликованного приключения не копируются в репозиторий.

Полный порядок работы: [CONTRIBUTING.md](CONTRIBUTING.md).

## Правовой статус

Это неофициальный фанатский/учебный проект. Он не связан с Wizards of the Coast. Репозиторий должен содержать только собственный код и оригинальные либо законно лицензированные материалы; опубликованный текст приключения, карты и иллюстрации сюда не включаются.
