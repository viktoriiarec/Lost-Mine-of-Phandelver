# Heart of Depths

Сюжетная RPG на Unity о памяти, личности и цене решений. Рабочее название репозитория — **Lost-Mine-of-Phandelver**, название проекта — **Heart of Depths / «Сердце Глубин»**.

## Текущая цель

Собрать вертикальный срез на 15–20 минут:

1. создание героя;
2. исследование локации через интерактивные точки;
3. диалог с проверками `2d6 + характеристика + навык − сложность`;
4. конфликт, который можно решить разговором, исследованием или боем;
5. последствия выбора и изменение Целостности личности.

Подробности: [вертикальный срез 0.1](docs/VERTICAL_SLICE.md).

## Быстрый запуск

1. Установить Unity 6 LTS.
2. Клонировать репозиторий и добавить его корневую папку в Unity Hub.
3. Дождаться импорта без красных ошибок.
4. Выбрать **Tools → Heart of Depths → Create Demo Scene**.
5. Нажать **Play**.
6. Для тестов открыть **Window → General → Test Runner → EditMode → Run All**.

Подробная инструкция: [docs/UNITY_SETUP_RU.md](docs/UNITY_SETUP_RU.md).

## Технологии

- Unity 6 LTS;
- C#;
- 2D-интерфейс для диалогов и исследования;
- небольшая тактическая арена;
- ScriptableObject для статических данных;
- обычные runtime-классы для изменяемого состояния.

## Главные правила

- `main` должна содержать запускаемое состояние проекта.
- Одна задача — одна ветка и один pull request.
- Имена веток: `feature/...`, `fix/...`, `docs/...`, `chore/...`.
- Статические данные хранятся в ScriptableObject; здоровье, Целостность, состояния и кулдауны — в runtime-объектах.
- UI не рассчитывает игровые правила, а только вызывает игровые системы и отображает результат.
- Новая механика получает тест или короткий воспроизводимый сценарий.
- Ассеты без ясной лицензии не добавляются; источник фиксируется в `THIRD_PARTY_NOTICES.md`.
- Закрытый код, тексты, персонажи и графика других игр не копируются.

Полный порядок работы: [CONTRIBUTING.md](CONTRIBUTING.md).
