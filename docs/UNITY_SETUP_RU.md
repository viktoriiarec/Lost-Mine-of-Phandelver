# Запуск прототипа в Unity

## Требования

- Unity Hub;
- Unity 6 LTS;
- модуль для нужной целевой платформы можно установить позже.

## Первый запуск

1. Клонируйте репозиторий.
2. В Unity Hub нажмите **Add → Add project from disk**.
3. Выберите корневую папку репозитория — ту, где лежат `Assets`, `Packages` и `ProjectSettings`.
4. Если Hub предложит открыть проект другой patch-версией Unity 6 LTS, согласитесь на обновление.
5. Дождитесь завершения импорта и компиляции.
6. Откройте **Window → General → Console** и убедитесь, что красных ошибок нет.
7. Выберите **Tools → Heart of Depths → Create Demo Scene**.
8. Unity создаст и откроет `Assets/HeartOfDepths/Scenes/Prototype.unity`.
9. Нажмите **Play**.

## Что проверять

- отображаются характеристики Рина;
- кнопка мнемантии делает проверку;
- видны два кубика, модификатор, сумма и исход;
- каждое использование отнимает 10 Целостности;
- Целостность не опускается ниже нуля;
- отказ от мнемантии меняет текст без броска.

## Запуск тестов

1. Откройте **Window → General → Test Runner**.
2. Выберите вкладку **EditMode**.
3. Нажмите **Run All**.
4. Все тесты `CoreRulesTests` должны быть зелёными.

## Если меню не появилось

- дождитесь окончания компиляции;
- проверьте Console;
- убедитесь, что папки `Assets`, `Packages` и `ProjectSettings` находятся в корне проекта;
- закройте и снова откройте Unity после импорта пакетов.
