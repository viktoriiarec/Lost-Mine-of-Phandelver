# Запуск прототипа в Unity

## Требования

- Unity Hub;
- Unity 6 LTS.

## Первый запуск

1. Клонируйте репозиторий.
2. В Unity Hub нажмите **Add → Add project from disk**.
3. Выберите корневую папку, где находятся `Assets`, `Packages` и `ProjectSettings`.
4. При предложении открыть проект другой patch-версией Unity 6 LTS согласитесь на обновление.
5. Дождитесь импорта и проверьте **Window → General → Console**.
6. Выберите **Tools → Lost Mine of Phandelver → Create Demo Scene**.
7. Откроется `Assets/LostMineOfPhandelver/Scenes/Prototype.unity`.
8. Нажмите **Play**.

## Что проверять

- отображаются шесть характеристик героя;
- проверка Восприятия бросает d20;
- видны бросок, модификатор Мудрости, бонус мастерства, итог и КС;
- успех позволяет заметить гоблинскую засаду;
- неудача запускает вариант внезапного нападения;
- повторная попытка сбрасывает сцену.

## Тесты

1. Откройте **Window → General → Test Runner**.
2. Выберите **EditMode**.
3. Нажмите **Run All**.
4. Все тесты `CoreRulesTests` должны быть зелёными.
