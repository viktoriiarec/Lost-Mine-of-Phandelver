# Вертикальный срез 0.1

## Цель

За 15–20 минут игрок должен почувствовать основную формулу:

> исследовать ситуацию → собрать сведения → выбрать подход → пройти конфликт → увидеть последствия.

## Сценарий

Рин и Мара находят разгромленный лагерь экспедиции у Вейлрока.

Игрок:

1. осматривает три интерактивные точки;
2. находит раненого Собирателя;
3. выбирает способ разговора;
4. проходит проверку `2d6 + характеристика + навык − сложность`;
5. получает полный успех, успех с ценой, неудачу с продвижением или тяжёлую неудачу;
6. решает, использовать ли мнемантию ценой Целостности;
7. избегает боя либо переходит на арену 8×8;
8. видит реакцию Мары и изменение следующей сцены.

## Тестовый герой

Рин: Мощь 4, Ловкость 2, Разум 3, Воля 4, Влияние 2, Целостность 100.

## Результаты проверки

| Итог | Результат |
|---:|---|
| 12+ | полный успех |
| 9–11 | успех с ценой |
| 6–8 | неудача с продвижением |
| 5 и ниже | тяжёлая неудача |

## Критерии приёмки

- Один seed даёт воспроизводимые броски в тестах.
- UI показывает кубики, модификаторы, итог и последствие.
- Целостность всегда остаётся в диапазоне 0–100.
- Любой исход диалога продолжает сцену.
- Бой можно избежать минимум двумя способами.
- После сцены сохраняются выбранный исход и состояние героя.

## Не входит в 0.1

- открытый мир;
- редактор внешности;
- сетевой режим;
- полноценный инвентарь;
- озвучка;
- сложная анимация;
- больше одного тактического боя.
